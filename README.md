# Pylon

![Pylon](docs/images/pylon.png)

Pylon is a resource-selling connector and earning node for the OpenAgents Compute Market. It allows contributor nodes to host local LLM inference engines, manage background resource-plane heartbeats, connect local Money Dev Kit (MDK) agent-wallets, and track Bitcoin/Satoshi earnings in real-time.

## Tech stack
- [Bun](https://bun.sh)
- [Effect](https://effect.website/)
- [OpenTUI](https://github.com/anomalyco/opentui)
